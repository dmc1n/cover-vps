# Cover pattern engine

Internal tool that turns 3D models of outdoor furniture into machine-ready DXF cutting patterns
for hot-air-welded acrylic covers. Start with CLAUDE.md (architecture, rules), docs/PLAN.md
(milestones), docs/DECISIONS.md (why things are the way they are).

Fresh server: `scripts/setup-vps.sh`, then paste `docs/KICKOFF_PROMPT.md` into Claude Code.
