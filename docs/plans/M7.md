# M7 plan: families, presets and batch

Written and built 2026-09-30 while the owner was offline (owner: "continue with M5, M6, M7").

- Families: `config/presets/<family>.yaml` as parameter layer 2, chosen per model in
  `cover.json` ("family"), in every command and in the web app.
- Status (draft, checked, production), tags and notes per model, in `cover.json`; search and
  filters in the web app's models list.
- Revisions: every export keeps its results and settings; compare any two (web tab
  Revisions, `cover diff` on the files).
- Batch: `cover batch --family F | --ids ...`; in the web app, select models and run; per model
  the panels changed by more than 1 mm.
- Tests: preset layering and precedence, status validation, revisions and comparison, a batch
  run with a changed setting, the API, and the browser flow.

Acceptance from PLAN.md ("20 models of one family processed with one preset") needs the
owner's models of one family (question 16); the tooling is ready.
