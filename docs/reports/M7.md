## What works now

- **Families:** a model can belong to a family (`config/presets/<family>.yaml`), whose
  settings apply to all its models unless a model sets its own. Order: company default →
  family → model → trial. First family: `table` (balloon under the cover).
- **Status, tags, notes** per model: draft, checked, production; tags to find models; notes
  for the machine operator. In the web app above the tabs, and searchable in the list.
- **Revisions:** every run that makes cut pieces is kept, with its settings and seams and
  `cut.dxf`. Web tab **Revisions**: pick two and see what changed.
- **Many models at once:** in the web app tick models and press **Run these**; on the command
  line `cover batch --family table`. Per model: which pieces changed by more than 1 mm.

How to use it: `docs/handbook/catalogue.md`.
