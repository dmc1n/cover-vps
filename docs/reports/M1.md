# M1 report: importing furniture models

Date: 2026-09-30. Status: done, but tested on made-up models only. No real manufacturer file
has been imported yet (see "Not yet tested").

## What works now

One command turns a manufacturer's 3D file into a clean model that the later steps start from:

```
uv run cover import <file> --out models/<id>
```

- **File types:** STEP, IGES, STL, OBJ, PLY and glTF/GLB.
- **Assemblies:** STEP part names and sub-assemblies are kept, e.g. `chair/frame/leg#2`. A part
  used many times (200 identical screws) is processed once.
- **Small parts:** parts smaller than 8 mm in every direction (screws, washers) are left out.
  This works even inside a single STL: the file is split into its separate bodies first.
- **Leaving parts out by name:** `--exclude "cushion*"`. Remembered for the next import of the
  same model.
- **Units:** taken from the file where it states them (STEP, IGES, glTF). For STL, OBJ and PLY
  you get mm unless you say otherwise. A model too small or too large for furniture gives a
  warning that names the units that would fit. The import never switches units by itself.
- **Standing on the floor:** lowest point at height 0, centred, front facing forward. `--up`
  and `--front` fix files drawn lying down or turned around.
- **Output:** `model.glb` opens in any 3D viewer at true size and upright. `model.json` holds
  the summary and `parts.json` lists every part, kept or not.
- **Same file, same result:** importing twice gives byte-identical files.
- `cover info models/<id>` shows the summary again.

How to use it, step by step: `docs/handbook/importing.md`.

## How to try it

```
make shapes
uv run cover import testdata/generated/chair_assembly.step --out models/test-chair
uv run cover info models/test-chair
```

Then open `models/test-chair/model.glb` in a glTF viewer (for example by dragging it onto
gltf-viewer.donmccurdy.com). The seat, back, legs and cushion show; the screws do not. To leave
out the cushion:

```
uv run cover import testdata/generated/chair_assembly.step --out models/test-chair --exclude "cushion*"
```

## Decisions made on the way (details in DECISIONS.md, ADR-022)

- IGES files store loose faces and no part names. They are "sewn" into bodies first
  (new setting `import.sew_tolerance_mm`, 0.1 mm). Exclusion by name does not work for IGES;
  ask manufacturers for STEP where possible.
- "Small" means the largest dimension is below 8 mm. A 40 mm bolt is therefore kept. That is
  usually harmless, because the cover surface bridges small bumps (M2). It can be excluded by
  name, or the limit raised.
- Six new settings in `config/defaults.yaml`, `import:` block: accuracy of curved surfaces,
  up axis, front, the size range for the unit warning, and the IGES sewing tolerance.
- Your model files stay private: `testdata/models/` and `models/` never go to GitHub, because the
  repository is public.
