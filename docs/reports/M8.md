# M8 report: fabric measurements (prepared)

Date: 2026-09-30. Status: the program side is ready; **the swatch tests are yours**
(question 17). Nothing changes in the patterns until the fabric is measured.

## What is ready

- **The test:** `docs/CALIBRATION.md`: strips along the warp, the weft and on the bias under a
  load, the permanent set after release, weld shrinkage along and across a seam, the smallest
  weld radius, the thickness.
- **The form:** `testdata/fabrics/measurements.template.json`: fill in a copy with the
  readings.
- **The conversion:** `uv run python scripts/fabric_profile.py <your file>` writes the fabric
  profile and prints the weld radius for the settings.
- **Compensation:** with `flatten.fabric_compensation: true` the flat pieces are made smaller
  by the fabric's stretch in a fitted cover (the average of warp and weft, since pieces can lie
  any way on the roll). Off now; the current profile holds placeholder values and a warning
  says so if it is switched on.

## What was measured

Automatic tests: a filled-in form becomes the right profile; the compensation is off by
default and 1 / 1.0075 with the placeholder values when switched on. 243 automatic tests pass.

## What comes next
